# 大塔实验 (Big Tower Experiment)

## 功能

实验用 mod：验证扩容后的运输塔在卸载 mod、回到原版存档后是否仍保留多出来的格子。

- 新建运输塔、或打开已有运输塔的窗口时，自动扩容到 9 格
- 运输塔窗口直接显示全部格子；窗口高过屏幕时会整体缩小
- 扩出来的格子支持传送带入塔、分拣器入塔、无人机/运输船卸货和沙盒模式的保持数量

格子数可在配置文件中修改（`TargetSlots`）。

## 安装

使用 r2modman 或 Thunderstore Mod Manager 安装。

## 注意事项

- 实验性质，使用前请备份存档
- 卸载后原版界面最多显示 6 格，第 7 格起不可见也不可修改
- 卸载后原版中传送带输入和分拣器放入只认前 5 格
- 卸载后原版中无人机/运输船往第 7 格起卸货时货物会丢失，卸载前请清空这些格子的需求
- 不支持多人游戏（未测试）
