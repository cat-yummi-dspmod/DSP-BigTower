# BigTower

兼容壳。本身不再改物流塔。

安装后会要求 [Station Assistant](https://github.com/cat-yummi-dspmod/DSP-StationAssistant) 在运行时把行星物流塔当作 8 格、星际物流塔当作 9 格，物流塔面板可翻页，总控面板不翻页，单页 6 格，并关掉「设置槽位数目」。不改 Station Assistant 的配置文件。卸掉 BigTower 后，这些要求消失。

Compatibility shim. It does not edit stations itself. While installed, it asks Station Assistant to treat planetary stations as 8 slots and interstellar stations as 9, with station-panel paging, no control-panel paging, page size 6, and the manual slot button off. Station Assistant's config file is left unchanged.
